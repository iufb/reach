# 0006. Графики статистики рисуем сами на Compose Canvas

- Статус: принято
- Дата: 2026-11-20

## Контекст

Статистика канала (PRODUCT.md §4.6, #155) приходит из TDLib графиками `StatisticalGraphData` — JSON в формате Telegram-чартов: колонки `x` (время) и `y0…yN`, у каждой серии тип (`line`, `bar`, `area`, `step`), имя и цвет, плюс флаги `stacked` / `percentage`. Нужно показать около десятка таких графиков на одном экране.

Варианты: библиотека для Compose (Vico и т. п.) или своя отрисовка.

## Решение

- Рисуем сами на `Canvas`: линии для `line` / `step` / `area`, столбики (с накоплением при `stacked`) для `bar`, легенда из `names` / `colors`, подписи первой и последней даты.
- JSON разбирается `org.json` из Android SDK, отдельный парсер не нужен.
- Масштабирование (`zoomToken`), выделение диапазона и подсказки по касанию не делаем: экран для обзора, а не для анализа.

## Последствия

- Новых зависимостей и роста APK нет; формат данных один и тот же для всех графиков, поэтому кода немного (`stats/Charts.kt`).
- Если понадобятся зум, тултипы или анимации — вернуться к выбору библиотеки; модель серий (`Chart`) от отрисовки отделена и переедет без изменений.
