# 0001. Все сборки только в GitHub Actions

- Статус: принято
- Дата: 2026-11-15

## Контекст

Разработка идёт на Mac (arm64). Скрипты сборки TDLib из `td/example/android` требуют x86_64-хост и ~8 ГБ RAM. Локальная сборка Android-приложения тоже съедает время и ресурсы.

## Решение

- TDLib и APK собираются **только в GitHub Actions**. Локально не компилируем и не упаковываем.
- Локально допустимы только Gradle sync в IDE и скачивание готовых артефактов (например, `tdlib.zip` для автодополнения по `TdApi.java`).
- Debug APK собирается на каждый push в любую ветку и на каждый PR. Артефакты хранятся 14 дней.
- На устройство APK ставится скриптом: `gh run download` + `adb install`.
- Все CI-сборки подписываются **одним фиксированным debug-keystore** из GitHub Secrets (base64), чтобы новые APK вставали поверх старых без переустановки и повторного входа.

## Последствия

- Цикл «правка → проверка на устройстве» длиннее: нужно ждать CI.
- Не нужны Docker, NDK и тяжёлый Android SDK-тулчейн на машине разработчика.
- Сборка воспроизводима и одинакова для всех.
