# 0003. `api_id` / `api_hash` только в GitHub Secrets

- Статус: принято
- Дата: 2026-11-15

## Контекст

Репозиторий публичный. Если чужой человек использует наш `api_id`, например для спама, Telegram может заблокировать ключ. Ключи всё равно зашиты в APK, так что Secrets защищают не от декомпиляции, а от утечки через публичный код и историю git.

## Решение

- Ключи хранятся только в GitHub Secrets `APP_ID` и `APP_HASH` и пробрасываются в `BuildConfig` при сборке в CI.
- Без секретов (Gradle sync в IDE, PR из форков) сборка проходит с пустыми значениями. Приложение тогда показывает понятную ошибку в рантайме.
- `local.properties` для ключей не используется (см. ADR-0001).
