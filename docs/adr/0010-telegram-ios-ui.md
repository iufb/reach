# 0010. UI повторяет Telegram iOS, брендинг свой

- Статус: принято
- Дата: 2026-11-21

## Контекст

До версии 0.6 интерфейс собирался из стандартных компонентов Material 3 без общего визуального языка: экраны выглядят по-разному, отступы и цвета подбирались на месте. Нужен один образец, по которому можно переносить экраны по одному и сверять результат. Варианты:

1. Свой дизайн с нуля: долго, и нет готового эталона для сверки.
2. Telegram Android: Material-подобный, мало отличается от того, что есть.
3. Telegram iOS: целостный, хорошо узнаваемый. Все экраны есть в Mobbin ([Telegram iOS](https://mobbin.com/apps/telegram-ios-44ac8dd4-0d80-468e-9851-c6db7df39b0b)), поэтому каждый экран можно сверить со скриншотом.

## Решение

Раскладка и визуал экранов повторяют Telegram iOS (эпик #192).

- **Вид — iOS, поведение — Android.** Системная кнопка и жест «назад», клавиатура, разрешения, уведомления, share-sheet и выбор файлов работают по-андроидному. iOS-жесты, которых нет в Android, не переносим.
- **Шрифт Inter** вместо SF Pro: у SF лицензия только для платформ Apple, а Inter близок к нему по метрикам. *Частично заменено [ADR-0011](0011-local-apple-fonts.md): Inter — шрифт по умолчанию, SF Pro — если выбран в Настройки → Шрифт.*
- **Светлая и тёмная темы**, обе по образцу iOS; тема берётся из системы.
- **Только существующие функции.** Перенос UI не добавляет возможностей: если на экране iOS есть то, чего Reach не умеет, этот элемент не рисуем.
- **Порядок работы:** экран из Mobbin → перенос → проверка на устройстве (сборка `dctest`, тестовый DC). Скриншоты Mobbin в репозиторий не кладём, в issue только ссылки.

**Брендинг остаётся своим** (принцип 1 в PRODUCT.md в силе):

- название «Reach» (с 0.11 без «(Unofficial)»: слова «Telegram» в названии нет), своя иконка; меняется только цвет её фона под новый акцент;
- в интерфейсе нет логотипа Telegram, самолётика и слова «Telegram» в названии приложения; **исключение — значок «Отправить»** (ниже);
- копируется раскладка экранов, но не графика Telegram: иллюстрации, анимированные логотипы и фирменные стикеры не переносим.

## Последствия

- Общая основа (#197) идёт первой: палитра, типографика, компоненты (списки-группы, навбар, таббар, пузыри), размытие под панелями. Экраны собираются из неё, а не из голых компонентов Material.
- Material 3 остаётся внутри как набор базовых компонентов, но тема и формы переопределены; стандартный вид Material в готовых экранах — признак незавершённого переноса.
- Каждый экран проверяется на устройстве против скриншота Mobbin, включая «прыжки» UI (screenrecord). Мёрдж — после зелёного CI и проверки на устройстве.
- Сходство с Telegram iOS становится ожидаемым, поэтому граница «раскладка да, бренд нет» должна держаться явно: при сомнении (иконка, иллюстрация, название) выбираем своё.

## Исключение: значок «Отправить» (2026-11-25, #373)

Владелец выбрал для кнопки отправки стрелку под углом iOS — мягкий треугольник, наклонённый вверх-вправо, — вместо материального «send». Вырез Telegram (прямой «сгиб» от угла) заменён дугой-прорезью знака Reach (ADR-0012): она открывается на задней кромке, широкая, и сходится к острию, деля стрелку на «чашу» и «холм», как в R.

Риск принят осознанно: на 44 dp белая наклонная стрелка с прорезью в синем круге похожа на логотип Telegram, отличие (дуга вместо прямого сгиба) заметно только крупно. Исключение касается только этого значка; логотип Telegram, самолётик в брендинге (иконка приложения, сплэш, экран входа, уведомления) по-прежнему запрещены. Если сходство станет проблемой (ToS, жалоба), значок меняется отдельно, без пересмотра остального.
