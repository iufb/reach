# 0009. Редактор фото — свой, на Compose, правки как описание

- Статус: принято
- Дата: 2026-11-20

## Контекст

Перед отправкой фото нужен редактор (PRODUCT.md §4.4, #180–#182): кроп и поворот, рисование и текст, фильтры и коррекция. Варианты:

1. Библиотеки: uCrop (кроп), PhotoEditor (рисование/текст/фильтры на GPUImage). Это View/Activity, у каждой свой конвейер и свой формат результата; связать их в один редактор с общей отменой и сбросом — сложнее, чем написать.
2. Свой редактор на Compose.

## Решение

Свой редактор, `photoedit/`.

- `PhotoEdit` — описание правок, а не пиксели: поворот и отражение, рамка, позже штрихи, тексты, фильтр и коррекция. Координаты — доли «повёрнутого» изображения (после поворота и отражения, до кропа): рисунок не съезжает при смене рамки, а поворот пересчитывает всё вместе.
- Исходник не меняется: «Отмена» — закрыть, «Сбросить» — `PhotoEdit.None`, повторное открытие возвращает прежние правки.
- `PhotoEditRenderer` собирает итог в полном разрешении (не больше 2560 px — Telegram всё равно ужмёт): поворот → цвет → рисунок → кроп, JPEG во временную папку `cache/edited`. Отредактированная копия заменяет фото в отправке; при отмене отправки — удаляется.
- Экран — полноэкранный `Dialog` поверх чата; инструменты — режимы одного экрана.

## Последствия

- Без новых зависимостей; один формат правок для всех инструментов.
- Предпросмотр рисуется тем же Compose `Canvas`, итог — `android.graphics.Canvas` с теми же координатами; расхождение возможно только в мелочах (сглаживание, шрифт текста).
- Фильтры — через `ColorMatrix`; если понадобятся эффекты сложнее матрицы (размытие, виньетка) — `RenderEffect`/AGSL поверх той же модели.
